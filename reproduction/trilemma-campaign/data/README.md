# Data policy

Do not place undocumented raw tensors or model weights directly in this directory.

For each dataset or capture, store a manifest with provenance, license/terms, preprocessing,
split logic, tokenizer version, content digest, schema, and storage location. If artifacts are
too large to commit, retain cryptographic checksums and an access/reproduction procedure.

Exploratory and confirmatory captures must use distinct, predeclared seed cohorts.
