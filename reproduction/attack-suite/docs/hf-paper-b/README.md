# Mirror of Paper B release documents from Hugging Face

Text documents from the Hugging Face dataset `Setloop/llm-attacker-paper-b` that were never in this repository. Copied unchanged from dataset revision `6a853d04eb50d7dd639cb0bf08354cc4a032278d` (20 September 2026), keeping the dataset's paths. Each file's Git blob hash equals the dataset's file hash.

Included: every `.md`, `.tex`, `.bib` and `.bbl` file not already present in this repository's history, plus the three top-level status files `PHASE2-STATUS.json`, `BINARY-VERIFICATION.json` and `p6-evidence-verification.json`. Evidence data (JSON records, captures, checkpoints, manifests, logs, PDFs) stays on Hugging Face.

The current manuscript is `paper/paper_b/`. The manuscripts under this directory are historical snapshots.
