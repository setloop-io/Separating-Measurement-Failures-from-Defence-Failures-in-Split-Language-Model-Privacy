# Interpretation clarification for the frozen adaptation amendment

The frozen `experiments/v4_adaptation.v1.json` describes SIP-versus-forward as isolating the stage-2 BRE contribution. That description is incorrect: SIP-versus-forward compares reconstruction methods; it does not isolate the added BRE stage. The manuscript and final analysis use the latter interpretation.

The prospective primary, all 15 secondary contrasts, their statistical family, inputs and execution budgets are unchanged. No new inferential contrast was added after seeing outcomes. The original amendment remains byte-for-byte preserved so this clarification is visible rather than silently rewritten into its historical record.
