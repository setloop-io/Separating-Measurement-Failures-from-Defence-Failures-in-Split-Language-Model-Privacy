# Generated outputs

Small results, resolved configurations, run logs, and analysis summaries are retained in Git.
Large tensors and the exact corpus inputs are distributed in the private reviewer evidence
release. See [retrieval and verification instructions](../docs/REVIEWER_EVIDENCE.md).

Original outputs and manifests are preserved byte for byte. The release index records the
path, size, and SHA-256 of every recovered output, corpus file, and run manifest. The
publication date is not a historical execution date or evidence of preregistration.

Prospectively, generated summaries must record their input manifest list, code revision,
command line, and checksum. Existing historical records do not meet every part of that
contract; see the [dated provenance audit](../evidence/audit-20260910/report.md).
